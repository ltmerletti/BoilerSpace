# Code of conduct

Keep project discussions respectful and useful. Critique code and ideas directly, explain disagreements, and make room for people with different levels of experience.

Harassment, discriminatory remarks, threats, sexual harassment, and publishing another person's private information are not acceptable. Do not share private course data, credentials, or screenshots containing someone else's personal information.

This applies to the project's issues, pull requests, discussions, and other project spaces. Maintainers may remove inappropriate content or restrict participation to keep those spaces safe and focused. The same expectations apply to maintainers.

Use GitHub's reporting controls for abusive content. For a concern requiring a private conversation with the maintainer, request a private contact channel without posting sensitive details publicly. Security issues should follow [SECURITY.md](SECURITY.md).
