# README images

The opening **hero.svg** is drawn directly in SVG, using the existing orbit logo, typography and geometric shapes. The service line names Brightspace, Ed, Piazza and Gradescope. The two matching lecture pages represent the course material BoilerSpace brings together. It contains no generated imagery or embedded bitmap assets. The rounded charcoal panel has transparent outer corners.

The product screenshots use the running extension and real course material. Model answers come from Purdue GenAI Studio conversations and are rendered through the current interface.

- **slide-explanation.png** shows slide 14, "Ways to label radiation," open in Brightspace beside a new production Ask conversation. The assistant read slides 13, 14 and 15, plus the Topic 1 learning goals, to distinguish the labeling schemes and identify the stated learning expectations.
- **exam-topics.png** shows the real Brightspace learning-goals page alongside a new exam-review conversation. The question asks for a topic list from the lecture slides and learning objectives, without naming particular topics or files to retrieve. The answer uses five lecture decks and an annotated lecture file. It also notes that the main Topic 6 file exceeds the reader's size limit and that a dedicated Topic 4 deck was not found.
- **ed-exam-guidance.png** shows a new answer to a broad question about the instructor's study guidance on Ed. The question does not name posts or supply the expected guidance.

Course labels and account details were changed in the page HTML for privacy. Conversation titles were shortened for display. Answer wording, citations and lookup results were retained. Automatic jobs were paused in the screenshot tab so capturing images did not trigger another sync or model request. The underlying conversations, course captures, browser profiles and evaluation reports are not included in the repository.

The slide viewer is set to single-page display for the capture. These conversations were run through the connected test profile, using the normal Ask flow and default model behavior. Older images in this directory, including the previous exam and single-question discussion examples, are retained for existing documentation links.
