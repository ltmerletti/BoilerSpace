# README screenshots

These screenshots use the running extension and real course material. Model answers come from Purdue GenAI Studio conversations and are rendered through the current interface.

- **slide-explanation.png** shows slide 14, "Ways to label radiation," open in Brightspace beside a new production Ask conversation. The assistant read slides 13, 14 and 15, plus the Topic 1 learning goals, to distinguish the labeling schemes and identify the stated learning expectations.
- **overview.png** shows the real Brightspace learning-goals page alongside a saved exam-review answer. The answer checks syllabus scope against lecture material and collects learning objectives.
- **exam-research.png** shows part of the expanded activity from that same conversation.
- **ed-clarification.png** replays a recorded answer that finds an instructor's tie-breaking rule for a project simulation.
- **piazza-update.png** replays a recorded answer that distinguishes a later deadline extension from an earlier one.

Course labels and account details were changed in the page HTML for privacy. Conversation titles were shortened for display. Answer wording, citations and lookup results were retained. Automatic jobs were paused in the screenshot tab so capturing images did not trigger another sync or model request. The underlying conversations, course captures, browser profiles and evaluation reports are not included in the repository.

The slide viewer is set to single-page display for the capture. The slide conversation was generated for this example through the connected test profile, using the normal Ask flow and default model behavior. The other conversations are saved runs. Older images in this directory are retained for existing documentation links.
